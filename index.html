Runs on your machine

OpenPublisher runs in your browser and as a desktop app, with no proprietary cloud lock-in. Your documents stay yours.

02

Hosted on GitHub

The web app, templates, documentation, and release downloads are delivered through GitHub infrastructure, so this page tracks those exact components live.

Offline resilience

Even during a hosting disruption, the desktop editions for Windows, macOS, Linux, and FreeBSD keep editing and exporting .pub and PDF layouts offline.
